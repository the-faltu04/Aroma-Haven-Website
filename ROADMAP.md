# Implementation Roadmap

1. **Architecture and foundation** — technical stack, trust boundaries, initial data model and public shell.
2. **Brand system** — refine wordmark/monogram, typography and audio direction. Photography is optional and will not block development; the stable media-slot system supports later uploads/replacements from Admin.
3. **Application shell** — responsive route groups, navigation, loading/error/empty states and accessibility.
4. **3D experience** — hybrid café/product scene, dynamic loading, reduced-motion and mobile fallback.
5. **Customer experience** — category menu, product detail, search, cart, guest checkout and accounts.
6. **Authentication** — wire selected provider(s), secure sessions and role permissions.
7. **Database/backend** — reviewed migrations, seed script, validation and service layer.
8. **Orders and checkout** — authoritative price/tax/delivery/coupon calculations, cash workflows and test payment adapter.
9. **Kitchen/tracking** — status lifecycle, kitchen display, real-time updates and in-dashboard notifications.
10. **Admin platform** — owner/manager/staff workflows, menu editor, table management, cancellations/refunds, reviews, coupons and settings.
11. **Customer/loyalty** — customer history, verified-order reviews and loyalty UI (financial rules gated).
12. **Analytics and messaging** — metrics from real records, contact inbox and notification centre.
13. **Verification** — unit/integration/e2e tests, security review and responsive/3D performance QA.
14. **Release preparation** — Render configuration, legal/policy review, owner data verification and production acceptance.
